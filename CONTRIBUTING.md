# Contributing

Projects must be related to S3-compatible object storage. Open-source projects are preferred, but proprietary and commercial projects are also welcome.

When adding a project:

- Include the project name, URL, license (if applicable), and a short description.
- Use the appropriate category and existing Markdown table format.
- Avoid duplicate entries.
- Update the category count in the table of contents.

To contribute, fork the repository, edit `README.md`, and submit a Pull Request.

Corrections and suggestions are also welcome through GitHub Issues.
